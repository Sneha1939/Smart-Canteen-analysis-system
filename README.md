# Smart-Canteen-analysis-system
A Python-based machine learning project to analyze canteen data, predict food demand, identify consumption patterns, and reduce food wastage using data visualization and predictive modeling.

## Overview
Smart Canteen System is a data-driven Python project designed to analyze canteen operations, predict daily food demand, understand customer consumption patterns, and reduce food wastage using machine learning and data visualization.

## Objectives
- Forecast daily food demand
- Analyze customer consumption patterns
- Identify popular food items and peak demand periods
- Detect high-wastage food items
- Provide insights for better food preparation planning

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Food demand prediction using machine learning
- Food wastage analysis
- Visualization of demand and wastage trends
- Actionable recommendations for canteen management
